Install the published package from [npm](https://www.npmjs.com/package/ngx-editra):

```sh
npm install ngx-editra
```

The version badge follows npm's `next` tag, not the development manifest. Monthly
downloads come from Shields.io using npm statistics. A new package can show
pending data while npm reports catch up. The download badge shows pending until npm statistics are available.
Counts cover the whole package,
not unique users or downloads of a specific version.

## Versions and channels

`next` is the prerelease channel. `latest` is a registry tag; it does not guarantee
a stable release. Check the registry before choosing a version:

```sh
npm view ngx-editra dist-tags
npm view ngx-editra@latest version peerDependencies
npm view ngx-editra versions --json
```

Use an exact published version for reproducible installs. Check that version's
Angular peer dependencies: the development branch may support a wider range than
an older npm release. See [compatibility](COMPATIBILITY.md),
[installation](INSTALLATION.md), and the [changelog](../CHANGELOG.md).
