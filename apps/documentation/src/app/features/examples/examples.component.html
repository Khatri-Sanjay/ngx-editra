Explore editing, formatting, media, and tables. This example uses the built library's public API and an Angular reactive form.

A few things to try

  1. Select a sentence, change its heading or colour, and use Undo.
  2. Insert a table, select a cell, and explore the table tools.
  3. Compare HTML, text, JSON, and Markdown output below the editor.
  4. Toggle readonly or disabled, then reset the form to a fresh draft.
